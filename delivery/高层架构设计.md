## 1. 需求概要

### 1.1 需求概要说明

Vorzai 是 Electron + React + TS 桌面级电商 AI Agent（v0.1.0），现有能力已覆盖 OGSM 管理闭环、业务链（订单/库存/结算）、9 专家 9 技能、多模型适配与 RBAC+ABAC 多租户。本期由"用户诉求双重定位（HR 管理 + 电商业务方案专家）"与"业务链闭环（立项→选品→组盘→订单→客服）"驱动，将桌面端从"HRMS 内核 + 业务链骨架"演进为贯通业务与人力资源的双定位系统。

- **部分借鉴**：钉钉 —— 借鉴点：账号/权限/通讯录组织模型（角色 + 委托权限点）、连接器市场架构（三方/自建 + 连接流编排）。不借鉴：闭源代码、电商业务专家能力。
- **部分借鉴**：飞书 —— 借鉴点：OGSM/OKR 四阶段闭环 + 仪表盘（完成率/对齐率）、企业知识库 + AI 问答 + 词典、aily Agent 常驻 + 工具调用 MCP。不借鉴：闭源代码、非电商专精。
- **部分借鉴**：Rasa —— 借鉴点：对话式"LLM 理解 + 确定性 Flow 执行"（CALM）架构，适合电商业务链组盘/客服可靠编排；完全 on-premise 合规。不借鉴：纯框架无 HR/电商业务/UI/多租户。
- **不借鉴（否决）**：北森 —— 否决理由：作为"系统级标杆"整体否决（纯 HR SaaS、闭源、电商业务专家能力为 0、场景契合度仅 4.0）；但其 HR 真实计算业务模型（薪酬/考勤/绩效算法）、三支柱组织模型、合规认证体系（等保三级/ISO27001）作为**领域业务模型参考**（自研实现，非系统采用）。

## 4. 方案决策

### 4.1 价值定位澄清

**定位三段式**：

```
对外价值（客户侧）: 为电商企业提供"HR 管理 + 电商业务方案专家"双定位桌面系统，将立项→选品→组盘→订单→客服业务链与 OGSM 人力目标贯通，使一线人员通过对话一句话完成组盘/客服/选品等重复操作，缩短业务处理周期。
对内价值（运营侧）: 一线提效（对话式工作流 + 企业专属 Skill 自动化重复操作）+ 管理风险可控（OGSM 闭环到人、RACI 责任矩阵、激励与试点灰度）+ 合规留痕（RBAC+ABAC 权限 + 审计 100% 可追溯）。
差异化价值        : 相比通用 OA/HR SaaS，Vorzai 以电商行业属性为内核（四态电商场景 + 业务链组盘/客服），且 100% 原创自研（参考 Dify/Rasa/钉钉/飞书理念但不采购、不复制），数据本地优先离线可用，无 SaaS 订阅与数据出境风险。
```

**与产品矩阵的关系**：本系统在"电商业务运营 + 人力资源管理"价值主线中承担核心双定位职责，与现有 Vorzai 底座（llm-platform / 多租户 / 连接器 / 业务链 / HRMS）形成完整业务闭环（见 §5.2、§5.3）。

### 5.3 业务闭环

**业务主链路**（端到端）：

```
立项(OGSM 目标分解) → 选品(对话式选品辅助) → 组盘(商品组合/毛利/库存预占) → 订单(订单/库存/结算) → 客服(问答/工单/转人工) → [反馈回路]
```

**关键反馈回路**：

| 回路 | 触发点 | 反馈对象 | 反馈机制 | 价值 |
| --- | --- | --- | --- | --- |
| 业务效果回路 | 客服/订单完结 | OGSM 目标与 RACI | T+1 离线统计（仪表盘完成率/对齐率） | 优化目标分解与责任人矩阵 |
| 运营监控回路 | 关键操作/异常（权限越权/对话失败） | 合规/运维 | 实时审计告警（AlertChannel: email/钉钉/飞书） | 快速响应合规风险 |
| 模型迭代回路 | 对话失败/知识缺失（人工标注） | 知识库/Skill | 知识入库 + Skill 调优（周度） | 提升对话与知识命中率 |

**运营主线**：
- 每日：一线通过对话工作台处理组盘/客服/选品；管理者看实时业务看板。
- 每周：HR/管理者复盘 OGSM 完成率/对齐率，调整 RACI 与激励。
- 每月：合规/运维导出审计报表，校验多租户隔离与操作留痕；决策者看人效/成本报表。
