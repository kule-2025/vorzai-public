## 二、逐条修改说明与验证

### 1. B5 · server strict 真正落地（此前两轮均「暂缓」）

**排查（先排查再方案）**：本轮用临时探针 `server/tsconfig.strict-probe.json`（`extends` 真实 tsconfig + `strict:true`）跑 `tsc --noEmit`，结果仅暴露 **1 处错误**：
```
src/routes/dialog.ts(24,62): error TS2345: Argument of type 'string | undefined' is not assignable to parameter of type 'string'.
```
即此前两轮修复（移除 `paths` hack + license/business/knowledge/dialog/incentive 潜在缺陷）已清掉其余 ~11 处，仅 `dialog.ts` 限流 key 生成器残留 1 处。

**修改**：
- `server/src/routes/dialog.ts:24`
  ```diff
  - keyGenerator: (req) => (req.user?.userId || ipKeyGenerator(req.ip) || 'anon') as string,
  + keyGenerator: (req) => (req.user?.userId || ipKeyGenerator(req.ip ?? '') || 'anon') as string,
  ```
- `server/tsconfig.json:8` `"strict": false` → `"strict": true`（删除临时探针文件）

**验证**：全 server `tsc --noEmit` **0 errors**；后端单测 **332/332** 通过（strict 不影响运行时）。

**收益**：消除「`strict:false` 掩盖历史宽松类型」的风险，与 React 前端 `tsconfig` 一致，全仓类型安全基线统一。

### 2. B8 · jsx-a11y 根因纠正与实际接入

**根因纠正（纠正前两轮误判）**：前续报告称「`eslint-plugin-jsx-a11y` 被 peer 冲突阻断（项目 pin `eslint@^10.8.0`，jsx-a11y 需 eslint≤9）」。实测核实为 **误判**：
- `node_modules/eslint` 实际安装 **10.8.0**，flat-config 插件 API 向后兼容；
- `eslint-plugin-jsx-a11y@6.10.2` 仅在其 `peerDependencies` 声明 `eslint: ^3..^9`（**声明范围局限，非真实不兼容**）；
- 以 `npm i -D eslint-plugin-jsx-a11y@^6.10.0 --legacy-peer-deps` 安装成功，且插件导出 `flatConfigs.recommended`，确认 flat-config 可用。

**修改**（`eslint.config.mjs`）：
- 引入 `jsx-a11y` 插件，限定作用于 `src/**/*.{ts,tsx}`（前端，不影响 server）；
- 启用 `languageOptions.parserOptions.projectService`（typed linting）——否则 `@typescript-eslint/no-misused-promises` 会对每个文件抛「需 project」错误；
- 接入 `jsx-a11y.flatConfigs.recommended`（warn 级，不阻塞 lint 流水线）；
- `ignores` 排除 `src/__tests__/**`（测试文件不在 projectService 的 tsconfig include 内，避免「not found by project service」解析错误）。

**修复的 7 处高价值 a11y 缺陷**：
| 文件 | 问题 | 修复 |
|------|------|------|
| `components/Common/Confirm.tsx` | `autoFocus` 破坏模态焦点链路 | 改用 `useEffect`+`ref` 在打开时聚焦确认按钮（WAI-ARIA modal 模式） |
| `views/Auth/AuthView.tsx` | 登录框 `autoFocus` | 移除，避免移动端意外唤起键盘 |
| `views/HRMS/OGSMTreeLive.tsx` | 行内编辑 `autoFocus` | 移除 |
| `views/Modules/InventoryAlerts.tsx` | `<span role="button" onClick>` 非语义、缺键盘可达 | 改为 `<button>` |
| `views/Modules/OGSMBoard.tsx` | `RaciDot` 的 `role` prop（实际是 RACI 类型 R/A/C/I）被当作 ARIA role | 重命名为 `type`，消除假 ARIA role |

**验证**：`npx eslint src` → **0 errors**（347 warnings 为 `no-static-element-interactions`/`label-has-associated-control`/`unused-vars` 等渐进 backlog，全部 warn 级非阻塞）；`eslint --print-config` exit 0。

### 4. lint 钩子修复（阻塞项，本批发现并修复）

**问题**：首轮 `git commit` 被 husky pre-commit 钩子回滚。根因：`package.json` 的 `lint-staged`（行135）配置 `"eslint --fix --ext ts,tsx"`，而 **eslint 10 flat-config 已移除 `--ext` 选项**，`eslint --fix --ext ts,tsx` 直接报错 → 钩子失败 → commit 中止并 revert。

**修改**（`package.json`）：
```diff
- "lint": "eslint src server/src --ext ts,tsx",
+ "lint": "eslint src server/src",
  ...
  "lint-staged": {
    "*.{ts,tsx}": [
-     "eslint --fix --ext ts,tsx"
+     "eslint --fix"
    ]
  }
```

**验证**：重新 `git add -A && git commit` 时 pre-commit 钩子（lint-staged → `eslint --fix`）**通过**，commit 成功落库。
