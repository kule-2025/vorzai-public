## Vorzai 怎么帮你解决

**1️⃣ 考勤审批排班算薪，一条线跑完，HR 不用再抱 Excel 对账**
周视图拖拽排班，时间冲突和连续超时自动检测；排班发布直接联动考勤，员工出勤基准自动生成；一键算薪接入中国个税累计预扣法和社保公积金，工资单自动计算并流转状态；请假、加班、调休线上审批，结果实时同步。招聘从职位发布到面试、Offer、入职建档全流程闭环，入职自动建员工档案。

**2️⃣ 订单库存采购售后，业务全闭环，不用再登 5 个后台**
选品组盘一键生成订单，订单履约状态全程跟踪；库存低于安全库存自动预警，基于近 30 天销量给出智能补货建议，库存盘点差异自动调整；采购单从提交到审批到入库全流程管理；售后工单自动分级（紧急/高/中/低），SLA 倒计时实时显示，超时自动升级并分配给低负载管理员。经营状态集中呈现，关键指标一眼掌握。

**3️⃣ 人效归因到岗，谁贡献大、瓶颈在哪，数据说了算**
人效驾驶舱把员工贡献和业绩产出对应起来，流量/人员/排班三效应分解帮你找到效率瓶颈；ROI 排名和标杆对比让激励方案有据可依；客户 RFM 画像五层分层，高价值客户和高流失风险客户一目了然，高风险客户可一键发起挽留营销直达增长引擎。营销活动效果数据自动回流，ROI 对比分析帮你看清哪场活动真正赚钱。

**4️⃣ AI 蜂群协作 + 六类预测，经营决策不再靠拍脑袋**
数据、运营、HR、财务、客服 5 位专家角色并行分析业务问题，多角色交叉验证后给出建议，不是简单的问答机器人；记忆进化根据用户反馈自动调整记忆优先级，回答越用越精准；六类智能预测覆盖销量趋势（线性回归+7天明细）、库存补货、现金流预警、客户流失（RFM 加权模型）、营销 ROI、人效趋势，为备货、资金、留客、用人提供数据参考。

**5️⃣ 7 大电商平台对接，商品订单自动同步，不用再手工导表**
抖店、淘宝、京东、拼多多、快手、Shopify、Amazon 平台连接器，授权凭证 AES-256-GCM 加密存储，商品和订单自动同步，同步任务可调度可监控；支付宝 RSA2 签名和微信支付 V3 加密完整对接，下单、查询、退款一条线走完。

**6️⃣ 数据本地存储，安全可控，支持离线使用**
业务数据存在本地，日常办公无需联网，仅首次激活和自动更新时需要网络；多租户数据隔离，角色权限矩阵服务端实时生效；安装包 SHA-512 完整性校验，支持崩溃恢复和数据备份一键恢复；双源自动更新（GitHub 主源 + Gitee 回退），后台静默下载，点击重启即完成，无需重装。

### 下载失败解决方案

如果下载到 80MB 左右中断，请尝试以下方法：

**方法 1：使用下载工具（推荐）**
- 使用任意支持断点续传的多线程下载工具
- 即使中断也能从断点继续，不必重头下载

**方法 2：浏览器重试**
- 按 `Ctrl+J` 打开下载页，点击失败的任务选择"继续下载"
- 或使用无痕模式重新下载

**方法 3：命令行下载**
```bash
# 使用 curl（支持断点续传）
curl -L -C - -o Vorzai-0.2.110-Setup.exe "https://github.com/kule-2025/vorzai-public/releases/download/v0.2.110/Vorzai-0.2.110-Setup.exe"

# 或使用 wget
wget -c "https://github.com/kule-2025/vorzai-public/releases/download/v0.2.110/Vorzai-0.2.110-Setup.exe"
```

**方法 4：GitHub 加速镜像**
- 使用任意 GitHub 加速镜像服务，将下载链接中的 `github.com` 替换为对应加速域名

## 自动更新说明

Vorzai 内置双源自动更新机制，支持准无感更新：

1. **主源（GitHub）**：应用启动时检查 GitHub Release 的 `latest.yml`，获取最新版本信息
2. **回退源（Gitee）**：当 GitHub 访问超时时，自动切换到 Gitee raw 通道获取 `latest.yml`
3. **后台静默下载**：发现新版本后自动在后台下载安装包，不影响正常使用
4. **静默安装**：下载完成后提示「重启更新」，用户点击后全程无安装向导界面（oneClick 静默安装），安装完成自动重启
5. **灰度发布**：更新按设备分桶逐步放量，`stagingPercentage=100` 表示全量发布
6. **完整性校验**：安装包通过 sha512 校验，确保下载内容未被篡改
7. **手动检查**：在应用内「设置 → 检查更新」可手动触发更新检测
