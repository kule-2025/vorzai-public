# Vorzai — 电商企业全员一体化智能办公与经营平台

> 一套系统覆盖全员办公、业务经营与人效管理，让考勤审批高效协同、让利润人效一目了然、让每个岗位的贡献可衡量。

## 解决的核心痛点

- **系统割裂**：OA 考勤、HR 人事、电商业务、财务数据分散在多个工具，信息不通、重复录入
- **人效看不清**：员工贡献无法归因到具体订单与利润，人力投入与业绩产出脱钩
- **经营管不全**：订单、库存、采购、财务分散在多平台，全局经营状态无法一眼掌握
- **操作效率低**：排班、算薪、绩效、复盘依赖手工表格，审批流程线下跑，耗时且易出错
- **决策靠经验**：选品、定价、人力配置缺乏数据支撑，试错成本高

## 核心能力

- **全员办公协同（OA）**：考勤打卡、审批流程、日程任务、公告通知，覆盖从老板到一线员工的日常办公
- **人力全链路**：员工档案、排班调休、薪酬绩效、招聘培训一体化管理
- **业务全闭环**：选品组盘、订单履约、库存采购、售后财务全流程打通
- **人效倍增**：人效驾驶舱实时洞察，瓶颈归因到岗，激励方案 ROI 可预测
- **AI 智能助手**：蜂群多专家协作、记忆进化洞察、智能问答、自动化工作流

## 为谁创造价值

电商企业全员——从老板的经营决策、运营的业务执行，到 HR 的人事管理、一线员工的考勤审批与任务协同，一套系统覆盖全岗位场景，让每个人的工作高效协同、每份贡献可衡量。

## 自动更新说明

Vorzai 内置双源自动更新机制，支持准无感更新：

1. **主源（GitHub）**：应用启动时检查 GitHub Release 的 `latest.yml`，获取最新版本信息
2. **回退源（Gitee）**：当 GitHub 访问超时时，自动切换到 Gitee raw 通道获取 `latest.yml`
3. **后台静默下载**：发现新版本后自动在后台下载安装包，不影响正常使用
4. **静默安装**：下载完成后提示「重启更新」，用户点击后全程无安装向导界面（oneClick 静默安装），安装完成自动重启
5. **灰度发布**：更新按设备分桶逐步放量，`stagingPercentage=100` 表示全量发布
6. **完整性校验**：安装包通过 sha512 校验，确保下载内容未被篡改
7. **手动检查**：在应用内「设置 → 检查更新」可手动触发更新检测
